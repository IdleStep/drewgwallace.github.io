Privacy Policy

Home Alert Backup. Last updated November 9, 2026.

Who this applies to

Home Alert Backup is a private tool operated by one person, Drew Wallace, for his own use. The only Google account that connects to it is the owner's own account. No other people sign in, and no data from anyone else is collected.

What data the tool handles

  • Still images captured by the owner's home security cameras when motion is detected, plus the file names those images are saved under.
  • An OAuth access and refresh token issued by Google, stored on the owner's own server so the tool can upload without a sign-in each time.

How the data is used

The images are uploaded to a folder in the owner's own Google Drive for the sole purpose of keeping an off-site backup. The data is not used for advertising, analytics, profiling, or any other purpose.

Google user data

The tool requests only the Google Drive "drive.file" scope, which limits access to files and folders the tool itself creates. It does not read, list, or modify any other content in the Google account. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Sharing and disclosure

The data is not sold, shared, or transferred to any third party. The developer and the sole user are the same person.

Storage and retention

Snapshots are stored only in the owner's Google Drive and are deleted automatically after 30 days. Tokens are kept on the owner's server with access restricted to administrators.

Revoking access

Access can be removed at any time from the Google Account security settings page under third-party access, or by deleting the tool's folder in Google Drive. Revoking access immediately stops all uploads.

Changes

If this policy changes, the updated version and date will appear on this page.

Contact

Questions can be sent through the contact links on drewgwallace.com.
